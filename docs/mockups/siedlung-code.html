Lichtung – Siedlung und Code

Mockup zu docs/konzept.md › Siedlungen und Codes. Alles ist durchklickbar: gründen, Code merken, mit Code weiterspielen (richtig ist moos biber laterne kiesel), Menü im Spiel, Siedlung wechseln oder löschen.

1 · Startbild beim ersten Besuch

Startbild und Hauptmenü in einem. Noch keine Siedlung auf diesem Gerät: gründen oder mit Code weiterspielen.

2 · Startbild mit Siedlungen auf diesem Gerät

Das Gerät kennt Moosbach und Birkenhain (z. B. Familien-Tablet). Antippen öffnet die Siedlung; das Kreuz entfernt sie nur von diesem Gerät – mit Rückgängig, die Siedlung selbst bleibt.

3 · Neue Siedlung gründen – und der Code

Name eingeben oder würfeln, gründen. Danach das Code-Kärtchen: vier Wörter, Kopieren, „Ich habe ihn notiert“.

4 · Mit Code weiterspielen

Ein Feld für alle vier Wörter, Einfügen geht auch. Jedes Wort wird gleich geprüft; bei Tippfehlern ein Vorschlag zum Antippen. Falscher Code: Meldung an festem Platz; nach drei Fehlversuchen eine Minute Pause.

5 · Im Spiel: Menü, Code anzeigen, Siedlung löschen

Oben im Menü steht die Siedlung. „Code anzeigen“ öffnet dasselbe Kärtchen wie beim Gründen. „Siedlung wechseln“ führt zum Startbild. Löschen ist endgültig – darum als einzige Stelle eine Rückfrage.

Zu entscheiden

  • Wortliste: rund 1.000 Wörter aus Wald und Dorf, ohne Umlaute und ß, gut zu tippen und nicht verwechselbar.
  • Neue Farbe „Gefahr“ (Ziegelrot) nur für Endgültiges – Siedlung löschen. Kommt in docs/design.md.
  • Wappen: Jede Siedlung bekommt eine Farbe aus ihrem Namen; später ein gemaltes Wappen an derselben Stelle.
  • Illustration im Startbild ist Platzhalter aus Spielmarken – später das gemalte Titelbild.
